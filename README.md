Sales Data Calculator

Project Description

This project is a simple Python program that analyzes sales data and calculates important statistics.

Features

- Displays sales values
- Calculates the number of sales
- Calculates total sales
- Calculates average sales
- Finds the highest sale
- Finds the lowest sale

Technologies Used

- Python

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

python sales_calculator.py

Output

The program displays the sales values, number of sales, total sales, average sales, highest sale, and lowest sale.
